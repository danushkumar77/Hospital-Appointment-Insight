# CareBridge Hospital Appointment Insight

## Overview
CareBridge Hospital Appointment Insight is a data science project that analyses hospital appointment information to identify patterns connected with missed appointments.

## Objectives
- Identify patterns of attendance at hospital appointments.
- Investigate differences between departments and week days in no-show rate.
- Analyze relations between waiting time, reminders and appointment status.
- Show no-shows predictions using the Random Forest Classifier algorithm.
- Show results in Excel charts and PivotTables.

## Workflow
1. Creation of synthetic data set.
2. Preprocessing and cleaning.
3. Exploratory Data Analysis (EDA).
4. Feature engineering.
5. Random Forest classification.
6. Visualization in Excel and recommendations.

## Technologies used
- Python.
- Pandas.
- Scikit-learn.
- Google Colab.
- Microsoft Excel.
- PivotTables and PivotCharts.

## Dataset
In this project we use sample synthetic dataset made for demonstration purposes and for learning. The data are not real and do not refer to any actual hospital records. Model validation should be done with real hospital records.

## Results
The project shows a workflow of appointment attendance analysis and no-show prediction. See notebook and Excel workbook for analysis and visualizations.
